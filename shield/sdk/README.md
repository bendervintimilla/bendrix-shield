# shield/sdk/

Paquete instalable `bendrix_shield` (y alias `shield.wrap`): `wrap(client,
token)` apunta cualquier cliente OpenAI al gateway con el token Shield del
agente en una línea. `@shield.tool(...)` y `shield.untrusted(doc)` llegan en
H4. Ejemplo mínimo en `examples/any-app/` (curl, Python y TS).
